Monthly Activity

Weekly activity notes, logs, and learning records — September 2026 through March 2027.

Week 1 · September 21–25, 2026

Orientation and Fundamentals of Web Development

  • Onboarding
  • Website Development
  • HTML · CSS · PHP
  • Database

Pada minggu pertama, magang diawali dengan onboarding dan pengenalan lingkungan kerja di AirNav Indonesia. Kegiatan teknis kemudian berfokus pada pembelajaran dasar-dasar pengembangan web menggunakan HTML, CSS, dan PHP. Proses pengembangan mencakup penyusunan struktur halaman web, perancangan antarmuka pengguna, penerapan fungsi dasar menggunakan PHP, serta percobaan integrasi basis data. Selain itu, dilakukan penyesuaian tata letak dan pengujian antarmuka untuk memahami alur kerja pengembangan web dengan lebih baik, mulai dari implementasi frontend hingga koneksi basis data.

Week 2 · September 28 – October 2, 2026

Web Development and INMC Dashboard Planning

  • Website Development
  • INMC Dashboard
  • Work Plan
  • Portfolio Website

Pada minggu kedua, kegiatan difokuskan pada pengembangan website dan perencanaan sistem untuk dashboard INMC (Indonesia Network Management Center). Pengembangan website meliputi penambahan komponen antarmuka, perbaikan struktur halaman, serta pengujian tampilan dan fungsi website. Selain itu, aplikasi Hermes diinstal dan dieksplorasi untuk memahami fitur dan fungsi dasarnya.

Untuk pengembangan dashboard INMC, saya mengikuti diskusi teknis bersama tim untuk mengidentifikasi kebutuhan sistem, menetapkan fitur utama, dan menentukan informasi yang akan ditampilkan. Hasil diskusi didokumentasikan dalam rencana kerja pengembangan yang mencakup tahapan implementasi, kebutuhan komponen dashboard, dan target proyek. Pada minggu ini, saya juga mulai mengembangkan website portofolio pribadi dengan menyusun struktur halaman awal dan desain antarmukanya.

Week 3 · October 5–9, 2026

System Requirements Analysis and SWORD Dashboard UI Development

  • SWORD Dashboard
  • UI Design
  • Requirements Review

Pada minggu ketiga, kegiatan diawali dengan meninjau dan menyempurnakan rencana kerja pengembangan dashboard INMC, termasuk penyesuaian kebutuhan fitur, tahapan implementasi, dan target pengembangan. Saya juga meninjau data, fungsi, dan antarmuka dashboard untuk memastikan kesesuaiannya dengan kebutuhan sistem yang telah ditetapkan.

Kegiatan selanjutnya berfokus pada pengembangan frontend dashboard SWORD. Proses pengembangan mencakup perancangan struktur halaman, penataan komponen antarmuka pengguna, penyesuaian tata letak berdasarkan referensi desain, serta penyempurnaan elemen visual. Antarmuka disempurnakan secara bertahap dengan menekankan konsistensi desain, keterbacaan informasi, dan navigasi yang mudah digunakan agar dashboard lebih terstruktur dan mudah diakses.

Week 4 · October 12–16, 2026

Chatbot Development, User Administration, and SWORD System Integration

  • Chatbot
  • User Administration
  • System Integration
  • OWASP Top 10

Pada minggu keempat, kegiatan difokuskan pada pengembangan dan integrasi fitur secara kolaboratif di dalam website SWORD. Proses pengembangan diawali dengan pembagian tugas antaranggota tim untuk meminimalkan potensi konflik kode saat pengembangan berjalan bersamaan.

Saya terlibat dalam pengembangan fitur chatbot, meliputi perancangan antarmuka percakapan, pembuatan komponen interaktif, dan penyempurnaan alur interaksi pengguna. Selain itu, saya mengerjakan pengembangan fitur administrasi pengguna untuk mendukung pengelolaan data pengguna dan pengaturan hak akses di dalam website.

Dalam diskusi teknis bersama tim, beberapa rencana pengembangan sistem dibahas, termasuk penerapan autentikasi pengguna melalui registrasi dan login, pengelolaan hak akses dokumen regulasi dan standar, pelacakan riwayat unduhan dokumen, penerapan logging sistem, serta penguatan keamanan website berdasarkan OWASP Top 10. Diskusi juga membahas potensi penggunaan Claude Code sebagai AI agent untuk mendukung alur kerja pengembangan.

Pada akhir minggu, fitur chatbot dan administrasi pengguna yang sebelumnya dikembangkan secara terpisah diintegrasikan ke dalam satu halaman. Proses ini mencakup penggabungan komponen, penyesuaian struktur kode, dan peninjauan fungsi antarmuka untuk memastikan kedua fitur dapat berjalan bersamaan tanpa saling mengganggu. Kegiatan ini memberikan pengalaman praktis dalam integrasi modul, pengembangan kolaboratif, dan pengelolaan potensi konflik kode.
