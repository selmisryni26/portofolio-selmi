Monthly Activity

Weekly activity notes, logs, and learning records — September 2026 through March 2027.

Week 1 · September 21–25, 2026

Orientation and Fundamentals of Web Development

  • Onboarding
  • Website Development
  • HTML · CSS · PHP
  • Database

Pada minggu pertama, magang diawali dengan onboarding dan pengenalan lingkungan kerja di AirNav Indonesia. Kegiatan teknis kemudian berfokus pada pembelajaran dasar-dasar pengembangan web menggunakan HTML, CSS, dan PHP. Proses pengembangan mencakup penyusunan struktur halaman web, perancangan antarmuka pengguna, penerapan fungsi dasar menggunakan PHP, serta percobaan integrasi basis data. Selain itu, dilakukan penyesuaian tata letak dan pengujian antarmuka untuk memahami alur kerja pengembangan web dengan lebih baik, mulai dari implementasi frontend hingga koneksi basis data.

Week 2 · September 28 – October 2, 2026

Web Development and INMC Dashboard Planning

  • Website Development
  • INMC Dashboard
  • Work Plan
  • Portfolio Website

Pada minggu kedua, kegiatan difokuskan pada pengembangan website dan perencanaan sistem untuk dashboard INMC (Indonesia Network Management Center). Pengembangan website meliputi penambahan komponen antarmuka, perbaikan struktur halaman, serta pengujian tampilan dan fungsi website. Selain itu, aplikasi Hermes diinstal dan dieksplorasi untuk memahami fitur dan fungsi dasarnya.

Untuk pengembangan dashboard INMC, saya mengikuti diskusi teknis bersama tim untuk mengidentifikasi kebutuhan sistem, menetapkan fitur utama, dan menentukan informasi yang akan ditampilkan. Hasil diskusi didokumentasikan dalam rencana kerja pengembangan yang mencakup tahapan implementasi, kebutuhan komponen dashboard, dan target proyek. Pada minggu ini, saya juga mulai mengembangkan website portofolio pribadi dengan menyusun struktur halaman awal dan desain antarmukanya.

Week 3 · October 5–9, 2026

System Requirements Analysis and SWORD Dashboard UI Development

  • SWORD Dashboard
  • UI Design
  • Requirements Review

Pada minggu ketiga, kegiatan diawali dengan meninjau dan menyempurnakan rencana kerja pengembangan dashboard INMC, termasuk penyesuaian kebutuhan fitur, tahapan implementasi, dan target pengembangan. Saya juga meninjau data, fungsi, dan antarmuka dashboard untuk memastikan kesesuaiannya dengan kebutuhan sistem yang telah ditetapkan.

Kegiatan selanjutnya berfokus pada pengembangan frontend dashboard SWORD. Proses pengembangan mencakup perancangan struktur halaman, penataan komponen antarmuka pengguna, penyesuaian tata letak berdasarkan referensi desain, serta penyempurnaan elemen visual. Antarmuka disempurnakan secara bertahap dengan menekankan konsistensi desain, keterbacaan informasi, dan navigasi yang mudah digunakan agar dashboard lebih terstruktur dan mudah diakses.

Week 4 · October 12–16, 2026

Chatbot Development, User Administration, and SWORD System Integration

  • Chatbot
  • User Administration
  • System Integration
  • OWASP Top 10

Pada minggu keempat, kegiatan difokuskan pada pengembangan dan integrasi fitur secara kolaboratif di dalam website SWORD. Proses pengembangan diawali dengan pembagian tugas antaranggota tim untuk meminimalkan potensi konflik kode saat pengembangan berjalan bersamaan.

Saya terlibat dalam pengembangan fitur chatbot, meliputi perancangan antarmuka percakapan, pembuatan komponen interaktif, dan penyempurnaan alur interaksi pengguna. Selain itu, saya mengerjakan pengembangan fitur administrasi pengguna untuk mendukung pengelolaan data pengguna dan pengaturan hak akses di dalam website.

Dalam diskusi teknis bersama tim, beberapa rencana pengembangan sistem dibahas, termasuk penerapan autentikasi pengguna melalui registrasi dan login, pengelolaan hak akses dokumen regulasi dan standar, pelacakan riwayat unduhan dokumen, penerapan logging sistem, serta penguatan keamanan website berdasarkan OWASP Top 10. Diskusi juga membahas potensi penggunaan Claude Code sebagai AI agent untuk mendukung alur kerja pengembangan.

Pada akhir minggu, fitur chatbot dan administrasi pengguna yang sebelumnya dikembangkan secara terpisah diintegrasikan ke dalam satu halaman. Proses ini mencakup penggabungan komponen, penyesuaian struktur kode, dan peninjauan fungsi antarmuka untuk memastikan kedua fitur dapat berjalan bersamaan tanpa saling mengganggu. Kegiatan ini memberikan pengalaman praktis dalam integrasi modul, pengembangan kolaboratif, dan pengelolaan potensi konflik kode.

Week 5 · October 19–20, 2026

Website Maintenance, UI Adjustments, and Admin Dashboard CRUD

  • Portfolio Website
  • SWORD
  • CRUD
  • Admin Dashboard

Melakukan pemeliharaan dan pengembangan website portofolio serta website SWORD, meliputi pembaruan konten dan informasi, penyesuaian tampilan antarmuka (UI) pada halaman Home dan Profil, serta pengaturan struktur dan komponen halaman. Selain itu, mengimplementasikan fitur CRUD (Create, Read, Update, Delete) pada Admin Dashboard untuk mendukung pengelolaan data oleh administrator, mulai dari penambahan, penampilan, pengubahan, hingga penghapusan data. Kegiatan juga mencakup penyesuaian integrasi antara fungsi pengolahan data dan antarmuka serta pengujian untuk memastikan setiap fitur berjalan sesuai kebutuhan sistem.

Week 6 · October 21–23, 2026

Continued Development and Hardware Troubleshooting

  • Website Maintenance
  • Admin Dashboard
  • Hardware Troubleshooting

Melanjutkan pemeliharaan dan pengembangan website portofolio serta website SWORD, meliputi pembaruan konten, penyempurnaan fitur, penyesuaian komponen antarmuka (UI), dan pemeriksaan fungsionalitas sistem agar setiap halaman dan fitur berjalan sesuai kebutuhan. Pada website SWORD, dilakukan pengembangan lanjutan terhadap fitur Admin Dashboard serta penyesuaian kode dan integrasi antarkomponen. Selain itu, melakukan troubleshooting perangkat keras pada laptop yang mengalami kendala dalam mendeteksi hard disk eksternal melalui pengujian silang menggunakan perangkat penyimpanan dan laptop lain. Pemeriksaan menunjukkan bahwa hard disk dapat terdeteksi pada laptop berbeda, sedangkan pada laptop yang bersagnkutan tidak dapat mendeteksi beberapa perangkat penyimpanan USB, sehingga diperlukan pemeriksaan lebih lanjut pada port USB, driver, dan konfigurasi sistem.

Week 7 · November 2–6, 2026

System Flow Documentation and Landing Page Improvements

  • SWORD
  • Flowchart
  • Landing Page
  • Autofill

Melakukan pengembangan dan evaluasi website SWORD melalui peninjauan fungsionalitas fitur, mengikuti meeting mengenai pembahasan hasil pengembangan website ESTIM, serta perancangan dokumentasi alur sistem menggunakan flowchart. Perancangan flowchart mencakup pemetaan proses, percabangan keputusan, dan pembagian hak akses berdasarkan tiga peran pengguna, yaitu guest, user, dan super admin sebagai acuan alur navigasi dan otorisasi sistem. Selain itu, melakukan penyempurnaan antarmuka Landing Page serta mengimplementasikan fitur autofill pada halaman Saran dengan mengintegrasikan data profil pengguna yang sedang login ke dalam field nama dan email. Pengembangan tersebut mencakup penyesuaian komponen frontend, pengambilan data pengguna, pengaturan alur autentikasi, serta pengujian untuk memastikan kesesuaian akses dan pengisian data pada setiap fitur.

Week 8 · November 9–13, 2026

Super Admin Interface, Security Webinar, and GNSS RFI Research Paper

  • Super Admin UI
  • Cybersecurity
  • Research Paper

Melaksanakan pengembangan lanjutan website SWORD dengan berfokus pada penyempurnaan antarmuka Super Admin, evaluasi komponen halaman, serta validasi dokumentasi alur sistem berdasarkan implementasi fitur dan pembagian hak akses pengguna. Selain itu, mengikuti kegiatan peningkatan pemahaman mengenai keamanan informasi melalui webinar Siber AI, khususnya terkait ancaman phishing, keamanan tautan, dan validasi kode dari sumber eksternal. Selain itu, mengikuti evaluasi proyek bersama EVP Divisi Information Technology dan memperoleh penugasan research paper mengenai GNSS RFI (Global Navigation Satellite System Radio Frequency Interference). Dari sisi teknis dan penelitian, kegiatan meliputi pencarian referensi ilmiah periode lima tahun terakhir, penelaahan metode dan hasil penelitian terdahulu, perbandingan permasalahan yang diangkat, serta identifikasi research gap sebagai dasar penentuan peluang dan arah pengembangan topik penelitian.

Week 9 · November 16–20, 2026

INMC Project Planning and URS-Based SWORD Development

  • INMC
  • Project Planning
  • URS
  • Blog Feature

Melakukan perencanaan proyek pengembangan website INMC melalui penyusunan jadwal kerja menggunakan platform project management, mencakup pemetaan tahapan pengembangan, estimasi durasi, dan penentuan target penyelesaian. Selain itu, melanjutkan pengembangan website SWORD dengan menerapkan penyesuaian berdasarkan dokumen URS (User Requirements Specification) sebagai acuan implementasi. Pekerjaan teknis meliputi analisis kesesuaian kebutuhan terhadap fitur yang telah tersedia, pembaruan struktur konten, integrasi buku pedoman ke dalam website, serta pengembangan fitur unggah gambar pada halaman blog. Fitur tersebut dilengkapi dengan pembatasan akses sehingga hanya Super Admin yang memiliki kewenangan untuk menambahkan foto, termasuk penyesuaian proses pemilihan, pengunggahan, dan penampilan gambar pada halaman blog.
