Monthly Activity

Weekly activity notes, logs, and learning records — September 2026 through March 2027.

Week 1 · September 21–25, 2026

Orientation and Fundamentals of Web Development

  • Onboarding
  • Website Development
  • HTML · CSS · PHP
  • Database

During the first week, the internship began with onboarding and an introduction to the working environment at AirNav Indonesia. Technical activities then focused on learning the fundamentals of web development using HTML, CSS, and PHP. The development process included structuring web pages, designing user interfaces, implementing basic functionality using PHP, and experimenting with database integration. Additionally, layout adjustments and interface testing were conducted to gain a better understanding of the web development workflow, from frontend implementation to database connectivity.

Week 2 · September 28 – October 2, 2026

Web Development and INMC Dashboard Planning

  • Website Development
  • INMC Dashboard
  • Work Plan
  • Portfolio Website

During the second week, activities focused on website development and system planning for the INMC (Indonesia Network Management Center) dashboard. Website development involved adding interface components, improving page structures, and testing the website's appearance and functionality. Additionally, the Hermes application was installed and explored to understand its basic features and functionality.

For the INMC dashboard development, I participated in technical discussions with the team to identify system requirements, define essential features, and determine the information to be displayed. The discussion results were documented in a development work plan covering implementation stages, dashboard component requirements, and project milestones. During this week, I also began developing a personal portfolio website by creating its initial page structure and interface design.

Week 3 · October 5–9, 2026

System Requirements Analysis and SWORD Dashboard UI Development

  • SWORD Dashboard
  • UI Design
  • Requirements Review

During the third week, activities began with reviewing and refining the INMC dashboard development work plan, including adjustments to feature requirements, implementation stages, and development targets. I also reviewed the dashboard's data, functionality, and interface to ensure alignment with the defined system requirements.

Subsequent activities focused on the frontend development of the SWORD dashboard. The development process involved designing page structures, organizing user interface components, adjusting layouts based on design references, and improving visual elements. The interface was refined iteratively, emphasizing design consistency, information readability, and user-friendly navigation to create a more structured and accessible dashboard.

Week 4 · October 12–16, 2026

Chatbot Development, User Administration, and SWORD System Integration

  • Chatbot
  • User Administration
  • System Integration
  • OWASP Top 10

During the fourth week, activities focused on the collaborative development and integration of features within the SWORD website. The development process began with task distribution among team members to minimize potential code conflicts during simultaneous development.

I was involved in developing the chatbot feature, including designing the conversation interface, creating interactive components, and refining the user interaction flow. Additionally, I worked on developing the user administration feature to support user data management and access control within the website.

During technical discussions with the team, several system enhancement plans were addressed, including implementing user authentication through registration and login, managing access permissions for regulatory and standards documents, tracking document download history, implementing system logging, and strengthening website security based on the OWASP Top 10. The discussions also covered the potential use of Claude Code as an AI agent to support the development workflow.

At the end of the week, the chatbot and user administration features, which had previously been developed separately, were integrated into a single page. This process involved merging components, adjusting the code structure, and reviewing interface functionality to ensure both features could operate together without interfering with each other. These activities provided practical experience in module integration, collaborative development, and managing potential code conflicts.
